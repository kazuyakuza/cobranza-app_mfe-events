# TODO 02 — Shared Types, Event Constants, Payloads & Event Maps [DONE]

**Source of truth:** `docs/mfe-events-project-brief.md` (and this TODO)  
**Goal of this TODO only:** Implement the full **type-level contract**: shared primitives, `MFE_EVENTS` / `SHELL_EVENTS`, every payload interface, and `MfeEventMap` / `ShellEventMap`. Wire them through the public API. **No helpers yet. No class-validator runtime yet. No USAGE.md.**

## Constraints

- Follow the brief catalog **exactly** (event names, payload shapes, required `schemaVersion`).
- **No** `createMfeEvent` / `isMfeEvent` / `dispatch*` in this TODO (TODO 03).
- Payloads remain **interfaces** (plain data). Runtime validation with `class-validator` / `class-transformer` comes in a later TODO together with helpers; do not add those dependencies here unless required to compile (they are not).
- `instanceId` is a `string` that **represents a UUID** (do not pull in a UUID package only for a type alias unless the repo already has one; a branded type or documented `string` is enough).
- Every public export must have clear **JSDoc** (who emits, who listens, purpose) so AI agents can use the API later.
- Keep modules focused: constants in `events.ts`, primitives + maps in `types.ts`, payload interfaces in `payloads.ts`.

- [x] Export:

  ```ts

  export const SCHEMA_VERSION = 1 as const;

  export type ModuleStatus =
    | 'loading'
    | 'loaded'
    | 'success'
    | 'warning'
    | 'error'
    | 'dirty'
    | null;

    moduleType: string;
    /** Unique per instance (UUID string); generated by the Shell */

  }
  ```

### 3. Payload interfaces (`src/payloads.ts`)

Implement **exactly** these interfaces. Import `ModuleIdentity`, `ModuleStatus`, `ModuleSize` from `./types`.

**MFE → Shell**

- [x] `RequestAddModulePayload`
  - `moduleType: string`
  - `title?: string`
  - `initialData?: Record<string, unknown>`
  - `schemaVersion: number` (**required**)

- [x] `RequestFullscreenPayload extends ModuleIdentity`
  - `schemaVersion: number`

- [x] `RequestRemovePayload extends ModuleIdentity`
  - `schemaVersion: number`

- [x] `UpdateHeaderPayload extends ModuleIdentity`
  - `title?: string`
  - `status?: ModuleStatus`
  - `schemaVersion: number`

- [x] `ShowNotificationPayload`
  - `type: 'success' | 'warning' | 'error' | 'info'`
  - `message: string`
  - `title?: string`
  - `duration?: number`
  - `schemaVersion: number`
  - (No `moduleType` / `instanceId` — global Shell notification)

- [x] `ModuleReadyPayload extends ModuleIdentity`
  - `schemaVersion: number`

- [x] `ModuleErrorPayload extends ModuleIdentity`
  - `message: string`
  - `code?: string`
  - `schemaVersion: number`

**Shell → MFE**

- [x] `ModuleStatePayload extends ModuleIdentity`
  - `size: ModuleSize`
  - `width: number`
  - `height: number`
  - `isCollapsed: boolean`
  - `isFullscreen: boolean`
  - `schemaVersion: number`

- [x] `ThemeChangedPayload`
  - `theme: 'gray-intermediate' | string`
  - `schemaVersion: number`
  - (No module identity — global)

- [x] `VisibilityChangedPayload extends ModuleIdentity`
  - `visible: boolean`
  - `reason?: 'fullscreen' | 'collapse' | 'workbench' | string`
  - `schemaVersion: number`

**JSDoc rules for each payload**

- Who emits it
- Who listens
- Short purpose
- Note that `schemaVersion` is required and should match `SCHEMA_VERSION` for this library major

**Do not** add class-validator decorators here. Interfaces only.
