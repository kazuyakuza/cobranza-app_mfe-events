#### 2.2 Core rules (must follow)

Document clearly:

1. Only the **Shell** listens to `mfe:*` events.
2. MFEs **never** communicate with each other through these events (use Shell or BFF).
3. Almost every payload carries `moduleType` + `instanceId` (UUID from Shell) for multi-instance support.
4. Payloads must be JSON-serializable.
5. `schemaVersion` is **required** on every payload and must match `SCHEMA_VERSION`.
6. Fullscreen navigation and workbench composition are owned by the Shell; MFEs only *request*.
7. Header **content** (title, status) is owned by the MFE via `UPDATE_HEADER`; header **action visibility** is owned by the Shell / `@cobranza-apps/ui`.
